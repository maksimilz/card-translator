# AI Character Card Translator & Editor (100% Client-Side)

Инструмент, работающий на **100% на стороне браузера**, для перевода, редактирования и экспорта карточек персонажей ИИ в форматах **PNG** со встроенными метаданными (`tEXt` чанк `chara` / `ccv3`) и **JSON** (Character Card V2 Spec / SillyTavern / Chub.ai / TavernAI / Backyard AI / RisuAI).

---

## 🚀 Быстрый старт на рабочей машине

1. Дважды кликните по файлу **`start.bat`**.
2. Скрипт поднимет локальный сервер на Python и автоматически откроет страницу `http://localhost:8000` в вашем браузере.
3. Либо просто откройте файл **`index.html`** в любом современном браузере (Chrome, Edge, Firefox, Brave, Яндекс.Браузер).

---

## 🌟 Ключевые возможности

- **100% Client-side (Приватность и безопасность)**:
  - Никакой бэкенд не хранит ваши данные. Обработка картинок, парсинг чанков PNG и сборка происходят прямо в оперативной памяти браузера.
  - Ваши API-ключи хранятся только в локальном `localStorage` вашего браузера.

- **Две копии (Оригинал + Перевод)**:
  - В интерфейсе параллельно отображаются две колонки: **Оригинал** (слева) и **Перевод/Редактор** (справа).
  - Кнопки быстрого скачивания:
    - **`💾 Скачать перевод (PNG)`** — генерирует готовую карточку с вшитыми переведенными данными для SillyTavern.
    - **`Скачать перевод (JSON)`** — скачивает чистый V2 JSON перевода.
    - **`📥 Оригинал (PNG)`** — скачивает оригинальную карточку со всеми метаданными.
    - **`Скачать оригинал (JSON)`** — скачивает исходный JSON без изменений.

- **Умный перевод с сохранением структуры SillyTavern**:
  - Строго сохраняет переменные и макросы: `{{char}}`, `{{user}}`, `{{original}}`, `<START>`, XML/HTML теги, формат W++.
  - Сохраняет разметку диалогов: реплики в кавычках, действия в `*звездочках*`.
  - Возможность перевести как **всю карточку целиком в 1 клик**, так и **отдельные поля** (только первое сообщение, описание, сценарий или альтернативные приветствия).
  - Счетчик символов и расчет примерного расхода токенов для каждого поля.

- **Поддержка любых LLM**:
  - **OpenRouter** (Claude 3.5 Sonnet, DeepSeek V3 / R1, Gemini 2.5 Flash, GPT-4o-mini, Qwen 2.5 72B и любые другие).
  - **Ollama** (локально, `http://localhost:11434/v1`).
  - **LM Studio** (локально, `http://localhost:1234/v1`).
  - **Любой OpenAI-совместимый эндпоинт** (KoboldCpp, vLLM, TabbyAPI, llama.cpp server).
  - Кнопка **«🔄 Обновить список моделей»** сама опрашивает ваш сервер и подгружает доступные нейросети.

- **Смена аватара**:
  - Можно нажать на аватар персонажа и заменить изображение (PNG, JPG, WEBP) перед скачиванием карточки — метаданные перенесутся автоматически!

## ⚙️ Настройка локальных LLM (CORS)

При обращении браузера к локальным серверам требуется разрешить CORS:

### Для Ollama:
Запускайте Ollama с переменной окружения `OLLAMA_ORIGINS`:
```cmd
set OLLAMA_ORIGINS=* && ollama serve
```

### Для LM Studio:
1. Откройте вкладку **Developer** (иконка `<->` или Local Server).
2. Нажмите **Start Server**.
3. Включите переключатель **Enable CORS**.

## 📁 Структура проекта

- `index.html` — главное окно приложения.
- `start.bat` — скрипт автозапуска для Windows.
- `css/app.css` — стили темной темы (стилистика SillyTavern).
- `js/png-chunks.js` — парсер и генератор чанков PNG (`tEXt`, CRC-32, UTF-8 Base64).
- `js/card-parser.js` — нормализация спецификаций V2 / V3 / V1, подсчет токенов.
- `js/translator.js` — модуль общения с API нейросетей и промпты перевода.
- `js/app.js` — реактивный контроллер интерфейса, drag-and-drop, пакетный перевод.
- `demo/sample_character_card.png` — готовая тестовая карточка для проверки.
