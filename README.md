# Card Translator

Переводчик и редактор карточек персонажей для SillyTavern / Chub / JanitorAI / RisuAI.
Открывает **PNG** со встроенными метаданными (`chara` / `ccv3`, спецификации V1 / V2 / V3) и **JSON**,
переводит через любую OpenAI-совместимую модель и собирает готовую карточку обратно.

## Запуск

1. Дважды кликните **`start.bat`** (нужен Python 3).
2. Откроется `http://127.0.0.1:8000` — перетащите карточку в окно.

Открыть `index.html` двойным кликом нельзя: браузер не загружает модули страницы с `file://`.

Параметры `run.py`:

```
python run.py --port 8000      # свой порт
python run.py --no-browser     # не открывать браузер
python run.py --insecure       # не проверять TLS-сертификаты (корпоративные сети с подменой сертификатов)
```

## Как идёт перевод

1. **Паспорт персонажа.** Модель определяет пол, род глаголов, обращение к `{{user}}` (ты/вы), тон речи,
   глоссарий имён и переводы ключей лорбука. Паспорт можно поправить руками — правки применяются ко всем следующим переводам.
2. **Перевод.** Все поля, приветствия, теги и записи лорбука режутся на пакеты под лимит Max Tokens.
   Ответ идёт потоком, поля заполняются по мере готовности.
   - Если модель пропустила поле или ответ обрезан лимитом, поле повторяется отдельно; обрезанный текст не принимается.
   - Ошибка одного пакета не теряет остальные — неудавшиеся поля можно перевести кнопкой «Повторить неудавшиеся».
   - Ключи лорбука **добавляются** к оригинальным, а не заменяют их, чтобы записи срабатывали и на английском.
3. **Проверка.** Для каждого поля сравниваются макросы (`{{char}}`, `{{user}}`, `<START>` …) и парность `*звёздочек*`.
   Расхождения подсвечиваются оранжевым, текст при этом не трогается.

Макросы JanitorAI `{{sub}}` / `{{obj}}` при загрузке заменяются на `{{user}}`.

## Возможности

- Оригинал и перевод в одной строке для каждого поля, навигация по полям со статусами.
- Перевод одного поля, «только непереведённые» или всё заново.
- Черновик сохраняется автоматически (IndexedDB) — перезагрузка страницы не теряет работу.
- Экспорт: PNG перевода (Ctrl+S), JSON перевода, исходный PNG байт-в-байт, исходный JSON.
  Для карточек V3 записываются оба чанка — `chara` (V2) и `ccv3`; поля V3 сохраняются.
- Смена аватара перед экспортом.
- Ассистент: вопросы о персонаже и переработка карточки по заданию.

## Модели

| Провайдер | Примечание |
|---|---|
| Nano-GPT, другие облачные API | идут через встроенный прокси `run.py` (обход CORS) |
| OpenRouter | напрямую |
| Ollama | `set OLLAMA_ORIGINS=* && ollama serve` |
| LM Studio | Developer → Start Server → Enable CORS |
| KoboldCpp, vLLM, TabbyAPI, llama.cpp | «OpenAI-совместимый эндпоинт» |

API-ключ хранится только в `localStorage` браузера.

## Структура

- `index.html`, `css/app.css` — интерфейс.
- `js/app.js` — контроллер интерфейса: редактор, перевод, экспорт, черновик.
- `js/translator.js` — запросы к LLM (стриминг), промпты, пакеты, разбор ответа, проверки.
- `js/card-parser.js` — нормализация V1 / V2 / V3, подсчёт токенов.
- `js/png-chunks.js` — чтение и запись `tEXt`-чанков PNG.
- `js/draft-store.js` — автосохранение в IndexedDB.
- `run.py` — локальный сервер и CORS-прокси с поддержкой потоковых ответов.
